# 水产菜市 - 超链接样式系统

## 🎨 设计理念

基于**海洋流动**和**水波涟漪**的概念，设计了一套优雅且富有活力的超链接样式系统。

## 📋 样式列表

### 1. **基础链接样式**
- 默认的海洋蓝链接
- 平滑的颜色过渡

### 2. **主要链接** (`.link-primary`)
- 带渐变下划线动画
- 适用于导航和重要链接

### 3. **水波纹链接** (`.link-wave`)
- 悬停时产生水波纹扩散效果
- 海洋主题特色效果

### 4. **渐变边框链接** (`.link-border-gradient`)
- 悬停时显示动态渐变边框
- 精致的按钮式设计

### 5. **气泡链接** (`.link-bubble`)
- 悬停时出现上升的气泡装饰
- 生动有趣的交互效果

### 6. **下划线滑动链接**
- `.link-underline-left` - 从左滑入
- `.link-underline-center` - 从中间展开
- `.link-underline-right` - 从右滑入

### 7. **发光链接** (`.link-glow`)
- 悬停时产生发光效果
- 现代科技感设计

### 8. **箭头链接** (`.link-arrow`)
- 带动态箭头的导航链接
- 箭头悬停时向右移动

### 9. **卡片链接** (`.link-card`)
- 整个卡片可点击
- 适用于产品展示

### 10. **文本内链接** (`.link-text`)
- 段落中的柔和链接
- 不干扰阅读体验

### 11. **社交链接** (`.link-social`)
- 圆形背景的社交媒体链接
- 悬停时旋转效果

### 12. **按钮式链接**
- `.link-button-primary` - 主要CTA按钮
- `.link-button-secondary` - 次要CTA按钮

### 13. **面包屑链接** (`.link-breadcrumb`)
- 导航路径链接
- 自动添加分隔符

### 14. **标签链接** (`.link-tag`)
- 分类标签链接
- 悬停时填充效果

### 15. **禁用状态** (`.link-disabled`)
- 不可点击的禁用链接
- 半透明视觉效果

## 🚀 使用方法

### 在CSS中导入
样式文件已自动导入到项目中，可以直接使用。

### 在组件中使用
```tsx
// 主要链接
<a href="#" className="link-primary">查看详情</a>

// 水波纹链接
<a href="#" className="link-wave">探索产品</a>

// 按钮式链接
<a href="#" className="link-button-primary">立即购买</a>
```

## 🎯 设计特点

1. **海洋主题** - 所有颜色基于海洋蓝色调
2. **流畅动画** - 使用 cubic-bezier 缓动函数
3. **响应式设计** - 适配移动端和桌面端
4. **无障碍访问** - 支持键盘导航和焦点状态
5. **性能优化** - 使用 CSS 动画而非 JavaScript

## 📱 响应式支持

所有链接样式在移动端和桌面端都有良好的表现：
- 移动端：适当的触摸区域大小
- 桌面端：精细的悬停效果

## ♿ 无障碍特性

- 清晰的焦点状态
- 足够的颜色对比度
- 支持键盘导航
- 语义化的HTML结构
