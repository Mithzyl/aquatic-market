# 移动端样式重构规范

## 概述
- **摘要**：重构整个前端样式，使其完全符合移动端使用体验，解决当前样式在移动设备上的显示问题。
- **目的**：提供流畅、易用、美观的移动端购物体验。
- **目标用户**：主要使用移动设备购买水产品的用户。

## 当前问题
1. 页面布局在移动端显示不完整
2. 文字大小在手机上难以阅读
3. 按钮和交互元素太小，难以点击
4. 左侧分类导航在移动端遮挡内容
5. 商品卡片在手机上显示拥挤
6. 表单输入框在移动端体验差
7. 缺少移动端手势支持

## 重构目标
1. **移动优先设计** - 以移动端为首要设计目标
2. **响应式断点优化** - 完善 sm/md/lg/xl 断点
3. **触摸友好** - 按钮最小 44px，间距充足
4. **可读性优化** - 字体大小、行高适配移动端
5. **布局重构** - 移动端单列布局，桌面端多列
6. **导航优化** - 底部导航栏替代侧边栏
7. **性能优化** - 减少动画，优化加载

## 技术栈
- React 19 + TypeScript
- Tailwind CSS (移动优先)
- CSS Variables 主题系统
- 自定义移动端组件

## 设计规范

### 断点定义
```
sm: 640px   - 小屏手机
md: 768px   - 大屏手机/平板
lg: 1024px  - 平板/小桌面
xl: 1280px  - 桌面
```

### 移动端设计规范
- **字体大小**：正文 16px（避免iOS缩放），标题 20-24px
- **按钮高度**：最小 48px
- **间距**：基础 16px，大间距 24px
- **卡片内边距**：16-20px
- **触摸目标**：最小 44x44px
- **安全区域**：适配刘海屏、底部手势条

### 颜色系统（保持海洋主题）
```
主色：#0ea5e9 (ocean-500)
辅色：#f43f5e (coral-500)
背景：渐变蓝白
文字：#0c4a6e (深色) / #ffffff (浅色)
```

## 功能需求

### ADDED Requirements

#### Requirement: 移动优先布局
重构所有页面采用移动优先的响应式布局。

**Scenario: 用户在手机上浏览**
- **WHEN** 屏幕宽度 < 768px
- **THEN** 显示单列布局，内容全宽，底部固定导航
- **验证**：`human-judgment`

#### Requirement: 底部导航栏
实现移动端底部固定导航栏，替代侧边栏导航。

**Scenario: 用户在手机上导航**
- **WHEN** 用户点击底部导航图标
- **THEN** 跳转到对应页面，图标高亮显示
- **验证**：`human-judgment`

#### Requirement: 触摸优化
所有交互元素适配触摸操作。

**Scenario: 用户触摸按钮**
- **WHEN** 用户点击按钮
- **THEN** 按钮有足够大的点击区域（>= 44px）
- **验证**：`programmatic`

#### Requirement: 字体可读性
优化移动端字体大小和行高。

**Scenario: 用户阅读商品信息**
- **WHEN** 在手机上查看文字
- **THEN** 字体大小 >= 16px，行高 >= 1.5
- **验证**：`human-judgment`

### MODIFIED Requirements

#### Requirement: 商品卡片
重构商品卡片组件，移动端显示更合理。

**Scenario: 用户浏览商品**
- **WHEN** 在手机上查看商品列表
- **THEN** 卡片全宽显示，图片比例适配，信息清晰
- **验证**：`human-judgment`

#### Requirement: 购物车页面
重构购物车页面，移动端操作更便捷。

**Scenario: 用户管理购物车**
- **WHEN** 在手机上查看购物车
- **THEN** 商品列表可滑动删除，数量调整便捷
- **验证**：`human-judgment`

#### Requirement: 表单输入
优化所有表单在移动端的体验。

**Scenario: 用户填写表单**
- **WHEN** 在手机上输入信息
- **THEN** 输入框高度 >= 48px，字体 >= 16px，避免自动缩放
- **验证**：`human-judgment`

## 验收标准

### AC-1：移动优先布局 ✅
- 所有页面在移动端显示正常
- 内容不溢出，无需横向滚动
- 底部固定导航栏工作正常

### AC-2：触摸友好 ✅
- 所有按钮点击区域 >= 44x44px
- 表单输入框高度 >= 48px
- 支持滑动手势（如删除购物车商品）

### AC-3：可读性优化 ✅
- 正文字体 >= 16px
- 行高 >= 1.5
- 对比度符合 WCAG 标准

### AC-4：性能优化 ✅
- 移动端动画减少或简化
- 图片懒加载
- 首屏加载时间 < 3秒

### AC-5：兼容性 ✅
- iOS Safari 正常显示
- Android Chrome 正常显示
- 适配刘海屏、底部手势条

## 约束
- 保持现有功能不变
- 保持海洋主题配色
- 使用 Tailwind CSS 响应式类
- 支持 iOS 13+ 和 Android 8+
