## 验收标准检查

### AC-1：移动优先布局
- [ ] 所有页面在移动端显示正常
- [ ] 内容不溢出，无需横向滚动
- [ ] 底部固定导航栏工作正常

### AC-2：触摸友好
- [ ] 所有按钮点击区域 >= 44x44px
- [ ] 表单输入框高度 >= 48px
- [ ] 支持滑动手势（如删除购物车商品）

### AC-3：可读性优化
- [ ] 正文字体 >= 16px
- [ ] 行高 >= 1.5
- [ ] 对比度符合WCAG标准

### AC-4：性能优化
- [ ] 移动端动画减少或简化
- [ ] 图片懒加载
- [ ] 首屏加载时间 < 3秒

### AC-5：兼容性
- [ ] iOS Safari正常显示
- [ ] Android Chrome正常显示
- [ ] 适配刘海屏、底部手势条
