## Core Responsibilities

### API Integration
- Connect pages/components to real backend APIs
- Replace mock data with actual API calls
- Handle request/response lifecycle properly
- Ensure proper error handling and loading states

### Data Mapping Standardization
- Unify frontend consumption patterns for backend data structures
- Align field naming between frontend expectations and backend responses
- Create consistent data transformation layers
- Handle data type conversions and default values

### Mock Dependency Removal
- Remove core mock dependencies from production code paths
- Maintain appropriate fallbacks only when architecturally necessary
- Ensure clean separation between development mocks and production code

### State Management
- Explicitly handle loading, empty, error, and success states
- Provide proper user feedback for each state
- Ensure graceful error recovery and retry mechanisms
- Handle network timeouts and partial failures

### Code Quality & Testing
- Fix linting issues and ensure code style compliance
- Add or update frontend tests for integrated functionality
- Ensure all tests pass before handoff
- Maintain code quality standards

### Handoff Preparation
- Provide access paths for Visual QA
- Document expected change points clearly
- Identify key states that need verification
